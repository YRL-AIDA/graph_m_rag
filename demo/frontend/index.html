Как Graph-M-RAG отвечает на вопросы по документам

Документ не «просто индексируется» — он превращается в три взаимосвязанных представления: регионы, структурный граф и семантический граф. Ответ LLM строится по объединённому контексту всех трёх.

1

Разбиение на регионы

PDF анализируется layout-моделью: каждая страница делится на регионы — текст, заголовки, таблицы, изображения, подписи. Каждый регион получает координаты (bbox), номер страницы и тип.

text title table image equation

См. вкладку «Документ и регионы» →

2

Структурный граф

Регионы связываются в граф документа:

  • ORDER — порядок чтения (регион → следующий регион);
  • PARENT — иерархия (таблица → её подпись, изображение → caption);
  • SECTION — разбиение на секции по заголовкам.

Это позволяет восстанавливать контекст «вокруг» найденного региона: соседей по чтению, родителя, раздел.

3

Семантический граф

Из текста документа извлекаются сущности (персоны, организации, даты, события) и сообщества — кластеры связанных сущностей с отчётом-резюме. Граф хранится в Neo4j, эмбеддинги — в Qdrant.

Поиск идёт не только по фрагментам текста, но и по графу: вопрос → сущности → связанные регионы и сообщества.

См. вкладку «Графы» →
