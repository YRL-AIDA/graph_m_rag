# Service: Qdrant Vector Database API

## Identity
- Зона ответственности: Векторная БД — хранение и поиск эмбеддингов, FastAPI-обёртка над Qdrant
- Порт: 8000 (FastAPI-обёртка), 6333 (нативный Qdrant), 6334 (gRPC Qdrant)
- Хранилище: Собственное хранилище Qdrant (on-disk, путь по умолчанию — `./qdrant_storage`)

## Dependencies
| Сервис | Протокол | Назначение |
|--------|----------|------------|
| Qdrant Server | Qdrant REST/gRPC (qdrant-client driver) | Непосредственное хранилище векторов — создание коллекций, upsert точек, поиск |

## API
| Method | Path | Feature Spec | Purpose |
|--------|------|-------------|---------|
| GET | `/search` | [search.md](search.md) | Поиск ближайших векторов в коллекции `my_collection` (top-5, размерность 4) |
| POST | `/upsert_points` | [upsert.md](upsert.md) | Массовая вставка/обновление точек (векторов с payload) в коллекцию `my_collection` |

## Data Model
- Ссылки на Data Model Specs: отсутствуют — модели данных определены inline в `api.py`
  - Вход `GET /search`: `query_vector` — query-параметр типа `str` (comma-separated floats), преобразуется в `list[float]`
  - Вход `POST /upsert_points`: `points: list[dict]`, каждый dict содержит поля `id` (int/str), `vector` (list[float]), `payload` (dict, опционально)
  - Выход `GET /search`: `{"results": [{"id": ..., "score": ..., "payload": ...}]}`
  - Выход `POST /upsert_points`: `{"status": "upserted", "count": N}`
  - Коллекция: `my_collection` — размерность вектора 4, метрика COSINE

## Configuration
- Переменные окружения (Pydantic Settings, файл `.env`):
  | Переменная | Тип | По умолчанию | Назначение |
  |-----------|-----|-------------|------------|
  | `host` | `str` | `"0.0.0.0"` | Хост для запуска FastAPI-обёртки и одновременно хост для подключения Qdrant-клиента |
  | `port` | `int` | `8000` | Порт для запуска FastAPI-обёртки и одновременно порт для подключения Qdrant-клиента |
  | `api_key` | `str` | `""` | API-ключ для подключения к Qdrant Server (если требуется авторизация) |

- Точка входа: `main.py` → `run_api(host=settings.host, port=settings.port)` — запуск uvicorn с app из `api.py`
- Dockerfile:
  - Собирает бинарник Qdrant Server v1.16.3 из официального GitHub-релиза
  - Базовый образ: `ubuntu:22.04`
  - Экспонирует порты 6333 (REST) и 6334 (gRPC)
  - Команда запуска: `qdrant` (нативный Qdrant-сервер, без FastAPI-обёртки)

## Invariants
- Коллекция `my_collection` создаётся автоматически при старте FastAPI-приложения (lifespan), если не существует
- Размерность вектора в коллекции жёстко зафиксирована: **4**
- Метрика расстояния: **COSINE**
- Эндпоинт `/search` возвращает не более **5** ближайших результатов
- Поиск принимает вектор только размера **4**, иначе 400 Bad Request
- Формат query-вектора: comma-separated floats в query-параметре `query_vector`
- Upsert принимает список словарей с полями `id`, `vector`, `payload` (опционально)
- QdrantClient — синглтон, создаётся один раз при импорте модуля `api.py`, закрывается при shutdown lifespan
- При отсутствии `api_key` клиент подключается без аутентификации

## Exceptions
| Отклонение | Обоснование |
|-----------|-------------|
| Нет `dtype/` директории — Pydantic-модели определены inline в `api.py` (диктуемые структуры) | Переходный период: существующий код не рефакторился под Constitution P6 |
| Нет `prompts/` директории | Сервис не взаимодействует с LLM — промпты не требуются (соответствует P7) |
| Нет `specs/` директории до написания этой спецификации | Переходный период: это первый документационный spec для сервиса (соответствует 5.3) |
| Нет `manager.py` — бизнес-логика не вынесена из `api.py` | Код находится в начальной стадии; поиск и upsert тривиальны и не требуют отдельного менеджера |
| Имя коллекции `my_collection` вместо `documents` (как указано в I3), размерность 4 вместо 2048-dim | Пример/заглушка: код использует демонстрационные значения, не соответствующие интеграционному контракту I3 |
| `QDRANT_URL` формируется из `settings.host:settings.port` (0.0.0.0:8000), что совпадает с адресом FastAPI-обёртки, а не с нативным портом Qdrant (6333) | Отсутствует отдельная переменная для адреса Qdrant-сервера; код предполагает, что Qdrant и обёртка работают на одном хосте и порту, что не соответствует docker-образу |
